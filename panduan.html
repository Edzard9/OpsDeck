Cara Pakai OpsDeck

OpsDeck adalah dashboard untuk memantau VPS-mu dari satu layar. Semua angka dan log yang tampil di sini asli, dibaca langsung dari server dan diperbarui otomatis tiap beberapa detik — bukan simulasi. Halaman ini menjelaskan cara membaca tiap bagiannya dengan bahasa sehari-hari.

1. Telemetri — kesehatan server saat ini

CPU Load — seberapa sibuk prosesor. Di bawah 50% itu santai; mendekati 100% terus-menerus berarti server bekerja sangat keras.

RAM — pemakaian memori. Yang perlu diwaspadai kalau sudah di atas 85%.

Disk Usage — ruang penyimpanan yang terpakai dari total kapasitas.

API Round-Trip — waktu tempuh data dari browser-mu ke server dan kembali. Kecil = koneksi Tailscale-mu lancar.

Grafik Resource Usage History — riwayat CPU & RAM beberapa menit terakhir, berguna untuk melihat lonjakan.

Network & VPS Info — lalu lintas data masuk/keluar, kecepatan disk, status Docker, dan jumlah layanan yang aktif.

2. Daftar proses — apa saja yang sedang berjalan

Tabel ini menampilkan layanan asli yang hidup di server, lengkap dengan uptime (sudah berapa lama berjalan), pemakaian CPU, dan memori.

Contoh yang biasa muncul: code-server (VS Code di browser), Caddy, Tailscale, dan opencode — yang terakhir ini hanya muncul saat ada pekerjaan build yang sedang jalan.

Untuk sekarang daftar ini sifatnya lihat saja (read-only): belum bisa menyalakan/mematikan layanan dari dashboard.

3. Log — dua mode: Teknis & Awam

Mode Teknis menampilkan log mentah persis seperti ditulis sistem — cocok untuk yang paham membaca log.

Mode Awam menerjemahkan log yang sama menjadi kalimat biasa. Terjemahannya dibuat oleh aturan tetap di server — tanpa AI, tanpa biaya token, dan langsung tampil. Warna titik di tiap kejadian:

  • Hijau — kabar baik (mis. tunnel tersambung, login berhasil).
  • Abu — aktivitas normal sehari-hari.
  • Kuning — perlu diketahui, biasanya pulih sendiri (mis. tunnel menyambung ulang, percobaan login gagal dari internet).
  • Merah — ada yang gagal dan layak dicek.

Ganti mode lewat tombol Mode Awam / Mode Teknis di kepala terminal. Di Mode Awam, tab-tab di terminal berubah fungsi menjadi saringan: Semua, Waspada, Info.

4. Dock bawah — menu cepat

Pil kaca yang melayang di bawah layar adalah jalan pintas ke bagian-bagian halaman: Overview, Telemetry, Agents, dan Logs. Kaca penandanya (lensa) berpindah saat menu diklik, atau saat dock diseret dengan mouse/jari. Ia juga mengikuti posisimu saat halaman digulir.

5. Keamanan — kenapa harus lewat Tailscale

OpsDeck hanya mau diakses lewat jaringan Tailscale milikmu. Servernya tidak membuka pintu di alamat internet publik, jadi orang yang tidak tergabung di Tailscale-mu tidak bisa membuka halaman ini sama sekali — bukan sekadar tidak tahu kata sandinya.

Konsekuensinya: kalau halaman tidak terbuka, pastikan Tailscale di HP/laptop-mu sedang aktif dan masuk ke akun yang sama.

6. Kalau data berhenti bergerak

Coba urutan ini: (1) muat ulang halaman; (2) tekan tombol sinkron (ikon panah melingkar) di pil nama di atas; (3) cek Tailscale-mu aktif. Kalau masih diam, kemungkinan program server OpsDeck di VPS sedang mati (mis. setelah VPS restart) dan perlu dinyalakan lagi.
